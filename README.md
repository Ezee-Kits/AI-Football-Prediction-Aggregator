# AI-Football-Prediction-Aggregator
A Python-based AI-integrated football prediction aggregator that collects predictions from six sources Statarea, BetClan, Forebet, Accumulator Generator, FootballSuperTips, and Prematips—and organizes home-win, away-win, over 2.5 goals, BTTS, and other available prediction data into structured CSV files for multi-source comparison and analysis.
